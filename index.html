使用规则
合并后的统计逻辑

新增任务：按收到日期进入月度“新增”。完成以后，原任务仍保留在收到日。

完成任务：只有从已有 Todo/任务完成的项目会计入月度“本月完成”；直接记录的临时 Done 只计入“临时 Done”和时间块，不计入“本月完成”。

未完成：月度统计中的“未完成”按当前月月末口径计算，包含以前月份遗留、且截至该月末仍未完成的任务。

计划时间块：收到日期只用于统计“新增”；计划日期可以单独安排到任意一天。同一个未完成任务可以安排多个计划时间块。

时间轴：同一条时间轴左右对照。左侧显示安排到当天的计划 Todo 时间块，右侧显示实际 Done / 时间块。

今天继续：暂停计时并生成一段 time block，但任务仍保持未完成，适合当天还会继续做。

任务未完成：暂停计时并生成一段 time block，但不把任务标记完成，适合今天不再继续或只是记录阶段性工作。

任务总耗时：正式任务完成后，会自动累计该任务所有已记录的实际时间块，包括多次计时、今天继续和任务未完成产生的阶段性记录。

直接记录任务 / 时间块：适合补记临时任务。可以选择“任务已完成”或“任务未完成”；未完成只记录时间块，不计入完成数量。

默认值：类别默认为“工作”，下拉菜单可选择“＋自定义”，也可以在“数据/备份”里维护类别选项和类别颜色；优先级默认为“无”，月历一周从周一开始。

编辑任务
新的跨天计划建议在“每日时间轴 → 安排 Todo 计划时间块”里添加。时间使用 24 小时制，例如 09:30、17:45。这里的旧计划时间仅用于兼容早期数据。
